🐈 What ClaudeBar changes

ClaudeBar is built to be safe to try. Here's exactly what it changes, and how to undo each change.

What it changes

Nothing changes until you click Continue in setup. These are the places ClaudeBar changes, including your own settings and files:

PlaceWhat changesBackup
~/.config/claude-bar/ClaudeBar's own settings.Not needed: it's ClaudeBar's own.
~/.claude/claude-bar/ClaudeBar's own usage files, written by the status line.Not needed: it's ClaudeBar's own.
~/.claude/settings.jsonOnly the statusLine entry, so Claude Code shows usage. Every other setting stays.~/.claude/settings.json.claude-bar-backup-<time>
~/.claude/statusline-command.sh and ClaudeBar's helper filesClaudeBar's status line script, only if you chose ClaudeBar's status line. ClaudeBar's helper files next to it are listed below.~/.claude/statusline-command.sh.claude-bar-backup-<time> (only if you already had a different script)
Your Cat Office folderA small patch, so cats match the browser, helpers show and usage works without a terminal.<Cat Office>/.cat-office/patch-backup-<time>/

"Open at login" is only on if you turn it on in Settings.

ClaudeBar's own small files

ClaudeBar also keeps a few small files of its own. Also remove ClaudeBar moves some of them to the Trash, and leaves the others where they are:

  • ~/Library/Caches/ClaudeBar/ (pictures from Cat Office, shrunk for the menu bar) and ~/Library/Logs/ClaudeBar/ (Cat Office's output when ClaudeBar starts it). Also remove moves them to the Trash, along with ~/.config/claude-bar/ and ~/.claude/claude-bar/ from the table.
  • ~/.claude/claude-bar-hook.sh and ~/.claude/claude-bar-statusline.sh, only if you kept your own status line. They save ClaudeBar's data, then run your status line unchanged. Also remove moves them to the Trash when settings.json no longer runs them. While it still does, they stay, so your status line keeps working.
  • ~/.claude/claude-bar-statusline-original.json: ClaudeBar's record of your earlier status line, so it can put that line back. It stays, like every backup.
  • ~/.cat-office/plan-usage.json: ClaudeBar's status line writes your 5-hour and 7-day usage here so Cat Office can show it. It stays. You can move it to the Trash yourself.
  • ClaudeBar's macOS preferences: the Cat Office folder it last saw running, and the tab you last had open. They stay. To remove them, quit ClaudeBar, then run defaults delete com.jbclores.claudebar in Terminal.

What it never does

  • It talks only to the Cat Office on your own Mac (localhost), never the internet.
  • It never starts, stops or controls your Claude agents, and never touches your projects or git.
  • Nothing changes before you click Continue.
  • It never deletes your files. Removing ClaudeBar moves its own files to the Trash.

What can interrupt your work

Patching or unpatching Cat Office restarts it, which ends the Claude sessions running inside Cat Office. ClaudeBar warns you before it does. Claude Code sessions in your own terminal aren't affected.

How to undo

The easy way

Settings → Undo ClaudeBar's changes… lists what ClaudeBar changed on your Mac. Pick what to undo; everything is backed up first. Tick Also remove ClaudeBar to remove it too.

From Terminal: ~/Applications/ClaudeBar.app/Contents/MacOS/ClaudeBar --undo (add --remove to remove ClaudeBar too). If you run ClaudeBar from its project folder, use build/ClaudeBar.app/Contents/MacOS/ClaudeBar --undo.

By hand (if ClaudeBar won't run)

  • Cat Office: stop Cat Office, then copy the files from a .cat-office/patch-backup-* folder back into your Cat Office folder (same paths), move server/agent-bridge/cat-assignments.ts and tests/sim/cat-assignments.test.ts (the patch added them) to the Trash, and start Cat Office again. The oldest patch-backup-* folder holds the files from before ClaudeBar first patched it. ClaudeBar makes a new backup each time it patches, upgrades its patch or unpatches. Be careful: copying a backup back replaces those files, so any changes made to them since are lost, including a Cat Office update. Not sure? Download or unzip Cat Office again, or ask the teammate who shared it with you.
  • Status line: open ~/.claude/claude-bar-statusline-original.json. Its statusLine is exactly the entry you had before, saved as text. To read it, take what's between its outer quotes and change each \" to " and each \/ to /. If there's no statusLine in it (or it's null), you had no status line. In ~/.claude/settings.json, change only the statusLine entry: set it to that, or remove the entry if you had none. Leave every other setting alone. If the record names a scriptBackup, copy that file (in ~/.claude) back to ~/.claude/statusline-command.sh. If you edited ClaudeBar's script since, copy it somewhere first. Then move ClaudeBar's helper files (claude-bar-statusline.sh, claude-bar-hook.sh, claude-bar-statusline-original.json) from ~/.claude to the Trash. The settings.json.claude-bar-backup-* files are a last resort: copying one back replaces your whole settings.json, so you lose every setting changed since that backup, not just the status line.
  • ClaudeBar's own files: move ~/.config/claude-bar, ~/.claude/claude-bar, ~/Library/Caches/ClaudeBar and ~/Library/Logs/ClaudeBar to the Trash. If you like, also ~/.cat-office/plan-usage.json and ClaudeBar's preferences (see above).
  • Open at login: System Settings → General → Login Items, remove ClaudeBar.
  • The app: quit ClaudeBar and drag it to the Trash.

Changed your mind? You can undo everything in a minute, and set it up again whenever you like. Questions? Ask the teammate who shared ClaudeBar with you.
